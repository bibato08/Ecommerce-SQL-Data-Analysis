# 🛒 E-Commerce Sales & Customer Analysis — SQL Project

## 📌 Project Overview

This project focuses on analyzing **e-commerce sales and customer data using MySQL**. The goal is to extract meaningful business insights from customers, products, orders, and order-item data using SQL queries.

## 🗂️ Database Structure

The database is named:

```sql
ecommerce_sales
```

It contains four main tables:

### 1. Customers

Stores customer information.

| Column      | Data Type   | Description                |
| ----------- | ----------- | -------------------------- |
| customer_id | INT         | Unique customer ID         |
| country     | VARCHAR(50) | Customer's country         |
| signup_date | DATE        | Customer registration date |

**Primary Key:** `customer_id`

---

### 2. Products

Stores information about the products available in the store.

| Column       | Data Type    | Description         |
| ------------ | ------------ | ------------------- |
| product_id   | INT          | Unique product ID   |
| product_name | VARCHAR(100) | Name of the product |
| category     | VARCHAR(50)  | Product category    |

**Primary Key:** `product_id`

---

### 3. Orders

Stores customer order information.

| Column      | Data Type   | Description        |
| ----------- | ----------- | ------------------ |
| order_id    | INT         | Unique order ID    |
| customer_id | INT         | ID of the customer |
| order_date  | DATE        | Date of the order  |
| status      | VARCHAR(20) | Order status       |

**Primary Key:** `order_id`

**Foreign Key:** `customer_id` → `customers.customer_id`

---

### 4. Order Items

Stores individual products included in each order.

| Column     | Data Type     | Description               |
| ---------- | ------------- | ------------------------- |
| order_id   | INT           | Order ID                  |
| product_id | INT           | Product ID                |
| quantity   | INT           | Number of units purchased |
| price      | DECIMAL(10,2) | Price per unit            |

**Composite Primary Key:** `(order_id, product_id)`

**Foreign Keys:**

* `order_id` → `orders.order_id`
* `product_id` → `products.product_id`

## 🧮 Revenue Calculation

Revenue is calculated using:

```sql
quantity * price
```

For example:

```sql
SUM(oi.quantity * oi.price) AS total_revenue
```

Only orders with the status **`Completed`** are included in revenue-related analysis.
